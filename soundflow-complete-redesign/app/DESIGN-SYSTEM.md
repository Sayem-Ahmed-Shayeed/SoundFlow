# Soundflow Luxury-Minimalist Design System

## Direction

Quiet, dark, precise, editorial. The brand accent is a restrained orchid rather than a large gradient. Surfaces are separated primarily through spacing and hairline borders instead of stacked cards and shadows.

## Typography

- Display / page titles: Iowan Old Style / Palatino / Georgia fallback
- Interface: Inter / system sans-serif stack
- Paths / technical values: SFMono / Consolas / Liberation Mono
- Page title: 30–42px, regular serif
- Section title: 23px, regular serif
- Body / controls: 14–15px
- Secondary text: 12–13px
- Metadata: 10–12px

## Spacing

4 / 8 / 12 / 16 / 24 / 32 / 42 / 60px rhythm.

## Color roles

- App background: #0A0A0C
- Raised surface: #121216
- Secondary surface: #17171C
- Primary text: #F4F1EE
- Secondary text: #C8C3C0
- Muted text: #918B8A
- Hairline: #2B292D
- Brand orchid: #C98BBD
- Ready/success: #67C9A8
- Warning: #D9B66F
- Error: #E58C92

## Radius

- Inputs/buttons: 8px
- Medium panels: 12px
- Singular hero surface: 18px
- Pills only for compact statuses

## Motion

- 120–220ms for most UI transitions
- Recording pulse is the only persistent animation
- All animation collapses under `prefers-reduced-motion`

## Accessibility

- 42–44px minimum control height for primary controls
- Visible 2px focus ring
- State labels always combine color with text
- Responsive reading order remains logical
